# NONO: Blade of the Dawn

ブラウザで遊べる2Dアクションゲームです。ダウンロードやインストールは要りません。

## 遊び方（iPhone）

1. Safari でこのページのURLを開きます。
2. 共有ボタンを押して「ホーム画面に追加」を選びます。
3. ホーム画面にできたアイコンから起動します。ブラウザのバーが出ない全画面で遊べます。

セーブはその端末の中に保存されます。Safari で開いた場合とホーム画面のアイコンから開いた場合では、セーブが別々になります。遊ぶ場所はどちらか一方に決めてください。ブラウザの閲覧データを消すと、セーブも消えます。

## 遊び方のページ

物語・操作・旅のこつ・寄り道の紹介は [遊び方のページ](https://ukos.github.io/nono-playground/howto.html) にあります。ゲームの設定画面の「遊び方を見る」からも開けます。

## 補足

- 横画面でも縦画面でも遊べます。
- 設定にある「画面診断」は、画面の動きを調べるための表示です。ふだんはオフにしておきます。
